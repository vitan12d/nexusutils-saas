# فيتان سبورت

موقع رياضي عربي أصلي (Next.js) لعرض نتائج المباريات المباشرة، جداول الترتيب وتفاصيل المباريات، بهوية زرقاء ودعم كامل للغة العربية (RTL).

البيانات عبر [API-Football](https://www.api-football.com/).

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # ثم ضع مفتاحك في .env.local
npm run dev
```

## النشر على Vercel

1. ارفع المشروع إلى GitHub.
2. في Vercel: New Project → استورد المستودع.
3. أضف متغيرات البيئة:
   - `API_FOOTBALL_KEY` — مفتاح API-Football.
   - `ADMIN_PASSWORD` — كلمة مرور لوحة التحكم.
   - `ADMIN_SESSION_SECRET` — سلسلة عشوائية طويلة.
4. Storage → أنشئ KV واربطه (يضيف متغيرات KV تلقائياً).
5. Deploy.

لوحة التحكم متاحة على `/admin` — راجع `ADMIN.md`.

> لا تضع المفتاح داخل الكود ولا ترفعه إلى Git.

## ملاحظة بخصوص Google AdSense

الموقع أصلي وليس منسوخاً. لرفع فرص القبول: أضف صفحات “من نحن”، “سياسة الخصوصية”، “اتصل بنا”، ومحتوى إخباري أصيل منتظم.
